# AI Tools Used

This project was built with the assistance of AI tools to accelerate development and design within the 6-hour time limit.

1. **ChatGPT (GPT-4/GPT-4o):**
   - **Use Case:** Understanding the assignment constraints and data pack.
   - **Details:** Used initially to break down the provided PDF data pack, analyze the edge cases (like changing deadlines and ambiguous ownership), and clarify the core requirements of the evaluation.

2. **Claude 3 Opus:**
   - **Use Case:** Implementation Strategy and Architecture.
   - **Details:** Used to draft the high-level architecture document, design the deterministic resolution engine approach (prioritizing rule-based logic over LLM hallucination), and map out the JSON schema for commitments.

3. **Google Antigravity with Gemini Pro:**
   - **Use Case:** Code generation, debugging, and documentation.
   - **Details:** Used within the IDE to write the actual Python implementation (`agent.py`, `app.py`, `extract.py`), fix Streamlit CSS UI bugs, and generate the `README.md` and this log.
